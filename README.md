# House-Price-Predication-

**My House Price Prediction Project: Learning Machine Learning by Building**

I’m happy to share my House Price Prediction project, where I’m exploring how machine learning can solve real-world problems using Python.

While working on this project, I built a complete workflow, from generating a dataset and exploring the data to training models and creating a user-friendly web application with Streamlit.

Here’s what I worked with:

- **Python** for data processing and development
- **Pandas and NumPy** for data preparation
- **Matplotlib and Seaborn** for data visualization
- **Scikit-learn** to train and compare Linear Regression and Random Forest models
- **Streamlit** to build an interactive house price prediction app

The project considers factors such as area, bedrooms, bathrooms, location, property age, and parking to estimate house prices.

One thing I’m learning through this experience is that building a project is not just about writing code. It’s about understanding the data, solving errors, testing different approaches, and improving step by step.

I’m continuing to learn and build more projects to strengthen my skills in Python, Data Analytics, and Machine Learning.

Every project is another opportunity to grow.
